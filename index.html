Local EPFO passbook reader

Get your EPFO passbook balance into a simple dashboard

Open the official EPFO and NPS portals, log in yourself, then paste or import the content here. The app calculates PF/NPS totals, company-wise PF contributions, and Excel export in your browser.

Privacy-first No credential storage

EPFO authentication stays on the official website. Imported text remains in this browser tab.

1

Connect to EPFO

Launch the official EPFO passbook portal in a new tab. Complete UAN/password, CAPTCHA, and OTP there.

Browser security prevents this web app from silently reading another logged-in website. After login, copy the passbook table or save an HTML/text export and import it below. An Android WebView version could automate the import after your confirmation.

2

Optional: avoid copy/download with extension

Install the local Chrome/Edge extension from the extension/ folder. After manual EPFO login and passbook page load, it shows a small Passbook detected prompt on the EPFO page.

  1. Start this app with npm start.
  2. Open Chrome/Edge extensions and enable Developer mode.
  3. Load unpacked extension from this repository's extension/ folder.
  4. Click Import to dashboard in the EPFO page prompt.

Waiting for browser extension import from an EPFO tab.

3

Import PF passbook content

Optional LLM fallback: install Ollama locally, run ollama pull llama3.2:1b, then use this button if EPFO changes the page format.

Waiting for EPFO passbook content.

4

Manual PF projection baseline

Enter your current EPFO balance and last month employee/employer contributions. The app saves this locally and estimates future PF balance by assuming the same combined amount is deposited every completed month.

No saved PF projection baseline yet.

5

Import NPS statement from email

The local server can read recent emails where the subject contains nps and statement, then parse supported attachments. Credentials are used for this request only.

Gmail usually requires an app password with IMAP enabled. The NPS statement password is only used to open the attachment.

Waiting for NPS email import settings.

6

Import NPS holdings/statement manually

You can still open the official NPS CRA portal, log in yourself, then copy or export your holdings/statement text here.
