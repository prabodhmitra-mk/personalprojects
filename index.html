Google Sheets

Save to your Drive

This connects the dashboard to your own Google account and creates/updates a Google Sheet in your Drive. Google requires a one-time Client ID before a local app can show the sign-in screen.

Simple setup help
  1. Open Google Cloud Console.
  2. Create/select a project, then search for and enable Google Sheets API.
  3. Open APIs & Services -> OAuth consent screen and complete the basic app details.
  4. Open Credentials -> Create credentials -> OAuth client ID.
  5. Choose Web application.
  6. Add this under Authorized JavaScript origins: http://localhost:5173.
  7. Copy the generated Client ID and paste it below.
  8. Click Sign in and save. Google will ask which account to use.

Leave Spreadsheet ID blank the first time. A new Google Sheet will be created in your Drive; copy its ID back here if you want future saves to update the same file.

Not connected. Google settings are stored only in this browser.
